# NYC Yellow Taxi & Mobility Analytics — March 2025

## Project Overview
An end-to-end data analytics project using NYC Yellow Taxi trip records for March 2025.

The project uses Python for data cleaning and exploratory data analysis, MySQL for database management and business analysis, and Power BI for interactive dashboard development.

## Project Objectives
- Analyze taxi trip demand and travel patterns.
- Identify the busiest days and hours.
- Analyze pickup and drop-off locations.
- Understand revenue and payment patterns.
- Identify popular taxi routes.
- Build interactive business intelligence dashboards.

## Tools & Technologies
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- MySQL
- SQL
- Power BI
- DAX

## Dataset
Source: NYC Taxi & Limousine Commission (TLC)

Dataset: Yellow Taxi Trip Records — March 2025

Final cleaned dataset: 4,145,143 records.

## Project Workflow
1. Data loading and exploration using Python.
2. Data quality checks and cleaning.
3. Exploratory Data Analysis (EDA).
4. MySQL database creation and data import.
5. SQL business analysis using 21 questions.
6. Power BI data modeling and DAX measures.
7. Development of three interactive dashboards.

## Key Project Findings
- Total trips: 4,145,143
- Busiest hour: 6 PM
- Top pickup zone: Midtown Center
- Top drop-off zone: Upper East Side North
- Most popular route: Upper East Side South to Upper East Side North

## Important Data Notes
Some unusual and missing values were retained rather than automatically removed. Specific project-level filters were used for selected fare, distance and duration metrics.

Recorded revenue should not be interpreted as fully validated revenue.
